# BSCS26053_ProductWebsite

APERTURE is a 3-page product website for a photography-gear brand. It has a Home page, a Products page with five items, and a Contact page with a form, so visitors can browse the gear and get in touch.

I built it with HTML for the structure and CSS for the styling, and added JavaScript in Lab 5 for a welcome pop-up, an automatic footer year, and "Check Availability" buttons on the products.
